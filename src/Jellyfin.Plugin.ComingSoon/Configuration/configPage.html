Behaviour

Path inside the Jellyfin container. The plugin creates this folder and a Movies-type library on it, with internet metadata turned off. Don't put anything else in this folder.
Only used when the plugin creates the library. Rename it in Jellyfin any time; the plugin finds it by folder.
Set automatically once the plugin has created the library, so it never creates a second one. Clear it only if you deleted the library and want the plugin to create it again.
Item metadata and posters are only rewritten when the shown status changes, e.g. progress crossing this step. 1 gives the finest updates.
Default 60. Lower (e.g. 15) for livelier progress; each update redraws two small images and saves one database record. Apps show the new state when they reload (Home button, pull to refresh, reopening).
